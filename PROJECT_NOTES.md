# Provenance and reconstruction notes

This repository is an archival presentation of a **Spring 2024 CIS 235 team project**. It is not a new reproduction of the analytics.

## What is original

- The analysis and narrative within the 10-page PDF, apart from the changed first-page header and privacy redactions.
- The charts, extracted directly from the report PDF as PNG previews.
- The proposal in pages 7–10, which remains clearly a **proposal**, not an executed procurement program.

## What was changed for public sharing

- Removed the student roster, Slack identifiers, and university email addresses on page 1; replaced them with a generic project header.
- Removed project-lead contact information on page 7 and a phone contact on page 10.
- Removed active hyperlinks pointing to potentially private class/team resources.
- Added this README and project notes. No analytical figures or reported metrics were changed.

## Missing source files

The original dataset, Tableau workbook, and analysis scripts were not available when this portfolio copy was prepared. It would be inaccurate to describe the contents as executable or fully reproducible. Any future reimplementation should live in a clearly marked `reproduction/` folder, credit the source data, and separately explain any changed results or methods.

## Team attribution

The original team had six members. Individual contributions have not been verified from the retained report. The README uses team-based wording and does not claim sole authorship of the analysis.
